# SIPJOK - Aplikasi Manajemen Pembelajaran PJOK

Full-stack: React 18 + Vite (`client/`), Express + TypeScript (`server/`),
Drizzle ORM + PostgreSQL (`shared/schema.ts`). Live: https://thor.abyte.my.id.
Deploy ulang: `bash deploy/push-to-vps.sh`. Arahan desain: `DESIGN.md`.
